# מערכת הקורסים שלי · בר אילן

מערכת לתכנון מערכת שעות מתוך קטלוג הקורסים של אוניברסיטת בר אילן ([courses.biu.ac.il](https://courses.biu.ac.il/)):
מוסיפים קורסים לפי שנה וסמסטר, בוחרים קבוצות הרצאה ותרגול, בונים כמה חלופות ומשווים ביניהן,
ונעזרים בבנייה אוטומטית שמדרגת את הצירופים לפי מה שחשוב לכם.

נבנה על ידי **נועם בנימין**.

## שתי דרכים להשתמש

| | הרצה מקומית (במחשב) | הגרסה בגיטהאב (GitHub Pages) |
|---|---|---|
| הוספת קורסים ומשיכת נתונים מבר אילן | ✓ | – |
| רענון נתונים של קורס | ✓ | – |
| בחירת קבוצות, חלופות, השוואה, בנייה אוטומטית | ✓ | ✓ |
| זמנים חסומים, ביטול פעולה, ייצוא ליומן (‎.ics) | ✓ | ✓ |
| PDF מעוצב | קובץ PDF ישיר | דרך "הדפסה / שמירה כ-PDF" של הדפדפן |

הגרסה בגיטהאב היא קובץ HTML סטטי: אין לה שרת, ולכן היא לא יכולה לפנות לאתר של בר אילן.
היא מציגה את הנתונים שפורסמו מההרצה המקומית, ומסמנת בבירור שהיא גרסת צפייה.
שינויים שעושים בה נשמרים בדפדפן של אותו מכשיר בלבד.

## הרצה מקומית

דרישות: Windows, ‏Python 3, ‏Google Chrome והחבילה `playwright` (`pip install playwright`).

1. לוחצים פעמיים על `start.bat`.
2. האתר נפתח בכתובת `http://localhost:8765`. לצידו נפתח חלון Chrome ממוזער שדרכו נמשכים הנתונים מבר אילן.
3. אם אתר בר אילן מבקש אימות (captcha), החלון קופץ – פותרים פעם אחת וממשיכים.

## פרסום לגרסה בגיטהאב

1. באתר המקומי, בתחתית העמוד: **"פרסום לגרסה המקוונת"**. זה שומר את כל הקורסים, החלופות וההגדרות לקובץ `web/data/snapshot.json`.
2. מריצים את `publish.bat` (או `git add web/data/snapshot.json && git commit && git push`).
3. תוך דקה-שתיים הגרסה בגיטהאב מתעדכנת.

> **שימו לב:** ב-GitHub Pages חינמי המאגר ציבורי – כל מה שמפורסם (כולל הערות אישיות) גלוי לכל מי שנכנס.

### הגדרה חד-פעמית של GitHub Pages

ב-GitHub: ‏Settings ← Pages ← Source: **GitHub Actions**. מכאן כל `push` לענף `main` מפרסם את התיקייה `web` אוטומטית.

## מבנה

- `server.py` – שרת מקומי: מגיש את האתר, מושך נתונים מבר אילן דרך Chrome, מייצר PDF ושומר את קובץ הפרסום.
- `web/` – האתר עצמו (`index.html`, `app.js`, `style.css`, גופנים, `data/snapshot.json`).
- `start.bat` – הפעלה; `publish.bat` – העלאת הנתונים שפורסמו.
